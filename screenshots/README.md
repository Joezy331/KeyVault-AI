# Screenshots

本目录用于存放 KeyVault AI 的产品截图，供 GitHub README 与作品集展示。

## 命名规范

| 文件 | 内容 |
|------|------|
| `01-cover.png` | 封面（Dashboard 总览）— README 首页优先展示 |
| `02-dashboard.png` | Dashboard |
| `03-api-keys.png` | API Keys（卡片网格 + 搜索 + 增删改） |
| `04-add-key.png` | Add API Key |
| `05-key-detail.png` | Key Detail（Provider Logo + 用量趋势） |
| `06-playground.png` | API Playground（真实请求 + 响应 + Token） |
| `07-usage-analytics.png` | Usage Analytics |
| `08-security-center.png` | Security Center |
| `09-activity.png` | Activity（分类筛选） |
| `10-settings.png` | Settings（安全 / 外观 / 数据） |

## 生成方式（重要）

1. 启动应用：`npm start`（或运行桌面 `KeyVaultAI.exe`）。
2. 进入「设置 → Demo Data」生成演示数据（**明确标记为 Demo，绝不混淆真实数据**）。
3. 切换到目标视图，确认画面中**不出现任何真实 API Key、主密码或 Token**。
4. 截图并保存为上方对应文件名（建议 1440×900）。

> ⚠️ 切勿提交包含真实密钥 / 密码 / Token 的截图。
