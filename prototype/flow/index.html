02 / 作品集简版

作品集简版流程图

一页可放的主路径：Unlock → Dashboard → API Keys → Playground → Request → Usage Log → Analytics → 回到 Dashboard，并从 Dashboard 分出 Security Center。适合直接截图放进作品集。

03 / 核心数据闭环

API 使用数据闭环

整个项目最重要的产品逻辑：一次 API 请求不是终点，而是数据分析的起点。API Keys → Playground → Request → Usage Log → Analytics → Dashboard → 回到 API Keys，形成数据闭环。

04 / 安全防护

安全防护分支

Security Center 独立成支：评分 → 六项检查 → 建议 → 状态，最终安全态势反馈回 Dashboard，形成安全管理闭环。

05 / 辅助分支

活动与设置辅助分支

本地审计日志与设置项，所有事件与偏好最终反馈回 Dashboard，支撑产品透明度与可解释性。
