# KeyVault AI · 产品流程图（作品集级）

> 本地优先的 API Key 管理器与用量分析工具
> **管理 → 使用 → 记录 → 分析 → 优化**

这不是一张「页面跳转图」，而是 KeyVault 产品逻辑的可视化：
**用户安全管理 API Key → 使用 API → 产生真实请求 → 记录用量日志 → 分析使用情况 → 反馈到总览看板 → 继续管理和优化。**
KeyVault 不只是一个 API Key 管理器，而是一个围绕 API 使用行为形成数据闭环的本地工具。

## 核心闭环（视觉重点）

```
API 密钥 → API 测试台 → API 请求 → 用量日志 → 用量分析 → 总览看板 ─┐
   ↑                                                                          │
   └──────────────────────────────────────────────────────────────────────────┘
```

在 Full Flow 与 Portfolio Flow 中以 **accent 橙色（#B5764A）加粗回路**呈现，其余分支为中性灰线，一眼区分主循环与支线。

## 交互

- **悬停任意节点** → 浮出该节点的一句话产品说明（如 API 测试台：“用安全存储的密钥配置并发送 API 请求。”）
- **点击节点** → 跳转到高保真原型对应页面（`../app.html?view=…`），映射全部指向真实存在的视图，无伪造路径：

| 节点 | 跳转 |
|---|---|
| 解锁保险库 | `../app.html?locked=1` |
| 总览看板 | `../app.html?view=dashboard` |
| API 密钥 / 添加密钥 / 密钥详情 | `?view=apikeys` / `?view=addkey` / `?view=keydetail` |
| API 测试台 / API 请求 | `?view=playground` / `?view=requestdetail` |
| 用量日志 / 用量分析 | `?view=usage` |
| 安全中心 | `?view=security` |
| 活动日志 / 设置 | `?view=activity` / `?view=settings` |

## 设计规范

- 配色：背景 `#F6F4EF` · 卡片 `#FFFFFF` · 主文字 `#1F1F1D` · 次文字 `#6F6C66` · 边框 `#E4E0D8` · Accent `#B5764A`（低饱和暖陶土，仅用于核心闭环强调）
- 复用高保真原型的设计语言：同一系统字体栈（Segoe UI / 微软雅黑）、同一圆角体系（10/8px）、同一卡片风格（1px 描边 + 轻投影）、同一间距尺度
- 连线 1.5–2.6px 圆角转折 + 清晰箭头；核心闭环 2.6px accent 实线，普通流程 1.6px 灰实线，**反馈回流（活动/设置/安全态势回到总览看板）为 1.4px 灰色虚线圆角线**，沿画布边缘走「反馈总线」，避免斜穿节点
- 总览看板同一侧有多条连线时，用分数锚点（如 `left:0.3`）错开端点，避免箭头重叠
- 逻辑流程图（06）采用经典判定式样式：紫色渐变标题栏、蓝色处理框、橙色判断菱形、是/否分支标注；渲染器支持 `shape:'diamond'`、`cl` 自定义连线色与 `label/lx/ly` 分支标注
- 无渐变（逻辑流程图标题栏除外）、无发光、无科技蓝紫，保持 Quiet Developer Tool 的编辑质感
